### Key Highlights
- **100% On-Device Processing:** Hinge angle sensor data and fold state calculations run entirely on your physical device in real time.
- **Zero Personal Data Collection:** FlipFold does not collect, store, transmit, or sell personal identifiable information, location data, or contact lists.
- **No Ads:** The application is ad-free and does not utilize third-party advertising identifiers.
